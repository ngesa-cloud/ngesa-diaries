# Contributing to Ngesa Diaries 🕯️

Welcome to the **Ngesa Diaries** open-source repository!  
*Ngesa Diaries* is a community-driven, declassified archive and investigative audio documentary series exploring hidden Kenyan horror stories, urban legends, eerie folklore, and unsolved supernatural mysteries across all 47 counties of Kenya.

Hosted and maintained by **Dominic Nyongesa** ([@ngesa-cloud](https://github.com/ngesa-cloud)).

---

## 📜 What We Are Looking For

We welcome verified oral lore, eyewitness depositions, historical newspaper clippings, and declassified investigative files across these categories:

1. **Kenyan Folklore & Occult Traditions**:
   * E.g., The Night Runners (*Abanyasi* of Western Kenya, *Omoirori* of Kisii), traditional oathings, and spirit guilds.
2. **Urban Legends & Phantom Transit**:
   * E.g., Ghost buses on Ngong Road, vanishing hitchhikers along the Rift Valley (Salgaa, Kikopey, Sachangwan), haunted cinema halls.
3. **Haunted Geography & Sacred Sites**:
   * E.g., Menengai Crater (*Kirima kia Ngoma*), Gedi Ruins, sacred baobabs, Ol Doinyo Lengai whispers.
4. **Boarding School Horrors & Youth Nostalgia**:
   * E.g., The 3:00 AM marching combat boots, phantom bells in colonial dormitories, mirror games, dorm crypts.
5. **Coastal Paranormal & Jinn Lore**:
   * E.g., Mama Ngina cliffside apparitions, *Popobawa* accounts, *paka wa dukani*, oceanic spirits.
6. **Cryptid & Rainforest Enigmas**:
   * E.g., The *Chemosit* (Nandi Bear) of Kakamega Forest, giant serpents of Lake Victoria.
7. **Investigative Forensics & True Crime**:
   * E.g., Cult investigations (Shakahola), historical heists, unsolved missing persons.

## 🚀 How to Submit a Story

### Option 1: Open a GitHub Pull Request (Recommended)
1. Fork this repository:
   ```bash
   git clone https://github.com/ngesa-cloud/ngesa-diaries.git
   cd ngesa-diaries
   ```
2. Create a new branch:
   ```bash
   git checkout -b story/my-kenyan-horror-tale
   ```
3. Add a new case file in `cases/` using the Markdown template below, or append your case object to `episodes.json`.
4. Commit and push:
   ```bash
   git commit -m "feat(case): add Case 09 - The Haunted Acacia of Machakos"
   git push origin story/my-kenyan-horror-tale
   ```
5. Open a Pull Request for Dominic Nyongesa and the editorial team to review!

## 📝 Story Submission Template

When submitting a case file, please include the following metadata:

```markdown
# [CASE XX] Title of Kenyan Legend / Mystery

- **Location**: County, Sub-County, or exact highway / forest landmark
- **Approximate Era / Date**: (e.g. 1994, 2012, or Pre-Colonial Oral Lore)
- **Category**: [Folklore / Urban Legend / Boarding School / Cryptid / True Crime]
- **Witness Status**: [First-hand Eyewitness / Second-hand Family Lore / Folkloric Consensus]

## 1. The Incident / Legend
[Provide a narrative of what occurred, setting the atmospheric scene.]

## 2. Witness Depositions / Oral Accounts
[Quote specific elders, drivers, alumni, or locals who experienced the event.]

## 3. Anthropological or Scientific Perspectives
[Include local explanations, cultural context, or rational forensic/psychological perspectives.]
```

## ⚖️ Code of Conduct & Respect

* **Respect Sacred Beliefs**: When documenting cultural traditions and sacred geographical landmarks, maintain scholarly and respectful inquiry.
* **Sensitivity to Real Trauma**: For modern true crime cases (such as Shakahola), prioritize victim dignity and factual forensic reporting over sensationalism.
